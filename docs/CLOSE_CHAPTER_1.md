## Step 4 — Audio system (replaceable by design)
**Owner decision (private personal project):** may use Spirit Call's sounds and the owner's own music files. **Rules so it stays safe and swappable:**
- All third-party audio lives in `public/audio/` subfolders that are **git-ignored and excluded from any public deploy**; the game must run without them (synth/placeholder fallback). Log each file in `docs/ASSETS.md` as *private use, not redistributable* with its source. If the repo or build is ever made public, remove those folders first (note this in README).
- Codex may copy Spirit Call sound files from `ref/spirit-call/` into `public/audio/sfx/` as needed and may search the web for **free-licence (CC0/CC-BY)** SFX; commercial songs are supplied **only by the owner** into `public/audio/music/`.
**CL10 Audio architecture:** `src/audio/`: `AudioManager` (WebAudio, unlocks on first gesture), buses **master / music / sfx / ui** with ducking (music dips on heavy hits, pause, banners), cue→sound mapping in **one data file `src/content/audio-map.ts`** (cue id → list of variants, volume, pitch jitter ±6 %, cooldown, priority, bus, 3D-ish pan by screen x) fed by the existing **cue bus (H2)**; swappable **sound packs** (`public/audio/packs/<name>/manifest.json`; the pack is selected in settings so any sound can be replaced by editing the map or dropping a file); synth fallback for every cue so nothing is silent; loop/crossfade support.
**CL11 SFX coverage (every cue):** hit light/medium/heavy, crit, kill, dash tap/rush/charge/release, spin start/tick, stomp charge/slam, boost, overdrive start/end, perfect dodge, counter, rear hit, pickup, repair, wave start/clear, level complete, boss phase, boss intro/defeat, UI move/confirm/back, upgrade pick, ambient (vents hiss, distant machinery, wind), saw whine pitched with speed.
**CL12 Music:** folder `public/audio/music/` — owner drops files: `theme.mp3` (menu/lobby), any number of `battle-*.mp3`, optional `boss-*.mp3`, `results.mp3`. A `music.manifest.json` (auto-generated by a script `pnpm audio:scan`) lists tracks with optional BPM/loop points. Behaviour: lobby plays theme; levels shuffle battle tracks with crossfade; boss uses boss track (else battle); pause lowers volume; no repeats back-to-back; Heat/Overdrive can raise intensity (filter/volume) and `beat()` events (if BPM known) drive subtle pulses (edge lights, vents) — optional, off by default.
**CL13 Audio UI:** small corner button (speaker icon) on every screen → popover with **mute/unmute**, master, music and sfx sliders, track name + skip; M key toggles mute; settings saved and applied before first sound; respects `prefers-reduced-motion` unaffected; autoplay policy handled (first click/tap/key).
